# EarnMate India — Final Static Website

## Included
- Mobile-first public website
- English / Telugu / Hindi hero content
- Opportunity directory with 12 seeded listings
- Search and category/device/cost filters
- Personalized starting-path finder
- Income planning calculator
- Scam safety checklist
- Opportunity detail modal
- Official-source outbound links
- Responsive design
- No fake income guarantees

## Important
This is a launch-ready STATIC website, not a complete SaaS backend. It does not yet include:
- user accounts
- secure admin login
- cloud database
- user-submitted reports
- payment processing
- automated verification
- analytics backend

Those require a hosting/backend service and server-side security.

## Publish
Upload `index.html` to any static hosting provider that supports HTML. Connect your own domain if desired.

## Content policy
Before publishing a new opportunity, verify the official source, current eligibility, fees, and terms. Do not promise earnings.
